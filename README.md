# Scriptable habits and apple reminders
Minimalist widgets for Scriptable that integrate with Apple Reminders to display habits and daily tasks directly on your iPhone home screen. The widgets allow you to quickly track habits

# Requirements
* iPhone with iOS
* Scriptable
* Access to Apple Reminders

# How to use
## Moje Rutyny / Moje Rutyny. Miesiąc / Moje Rutyny. Small 
1. Create a reminder in the Rutyny reminder list.
2. Leave the reminder incomplete (it is used as the active habit template).
3. In the Notes field, add the schedule as the first item using the format:
   P:1,3,5
   You can add additional notes after a | character, for example:
   P:1,3,5 | Drink before breakfast.
## Moje Rutyny. No
1. Create a reminder in the Rutyny reminder list.
2. Set the reminder title to match the habit name used in the widget parameter (for example: FastFood).
3. Whenever the habit happens, create a reminder with the current date and time as the due date.
4. Mark the reminder as Completed.
